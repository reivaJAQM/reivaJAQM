### 👨‍💻 Sobre mí

Soy un apasionado del **Desarrollo Full Stack** y la **automatización de procesos**. Me enfoco en crear plataformas multiplataforma, bots de automatización y aplicaciones web eficientes.

- 🚀 **En qué trabajo:** Plataforma multiplataforma *Vocatio* y bots de automatización en Python.
- 🎓 **Especialidad:** TypeScript, Python, desarrollo web e infraestructura en contenedores Docker.
- 🎯 **Objetivo:** Desarrollar software limpio, modular y de alto impacto.
