## 🚀 Sobre Mí

Soy **Alejandro**, un desarrollador enfocado en la construcción de **plataformas multiplataforma**, **automatización de procesos** y **desarrollo web full stack**. Me apasiona crear soluciones eficientes, optimizar workflows mediante bots y desarrollar aplicaciones web modernas y escalables.

- 🔭 **Proyectos Actuales:** Desarrollo de plataformas para conectar servicios y herramientas de automatización.
- 💻 **Especialidad:** TypeScript, Python, desarrollo web (HTML/CSS/JS) y contenedores Docker.
- ⚡ **Enfoque:** Código limpio, arquitecturas sólidas y experiencia de usuario fluida.
- 🚀 **Despliegues:** Experiencia desplegando aplicaciones en plataformas cloud como Vercel.
